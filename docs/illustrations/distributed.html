Distributed: one server, workers where the work is

The server runs on an always-on host behind HTTPS. Workers run on the machines that have what the work needs, and connect out to the server, so they need no open port. The planner proposes a worker for each batch; a session waits while its worker is asleep.

  • Logins stay on their machine: a worker's Claude login and GitHub token never go to the server.
  • A local repo (a folder, no GitHub) belongs to one worker; its project's sessions run there.
  • The server sets no session limit: each worker says how many sessions it runs at once.
