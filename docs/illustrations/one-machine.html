One machine with Docker

docker compose up runs two containers: the server and one worker. Good for trying Dispatch, or for a single always-on box.

  • Setup: server.env and worker.env share one WORKER_TOKEN; the worker also needs CLAUDE_CODE_OAUTH_TOKEN (from claude setup-token).
  • Try it without Claude: RUNNER=fake in worker.env.
  • The phone needs HTTPS for push notifications and the installed app: put a reverse proxy in front (see the distributed setup).
